骑行账本 PWA 初版 - 安装说明

当前包含：
- 加油记录：日期、里程、挂牌价、实付金额、每升优惠/总额优惠、实际升数、满箱标记、备注
- 估算升数和优惠节省
- 保养维修记录：项目、费用、日期、里程、下次里程/日期提醒
- 本月费用、累计费用、加油量和优惠统计
- JSON 导出/导入备份
- 本地存储、基础离线缓存
- 可添加到 iPhone 主屏幕

重要限制：
1. 这是可运行的 PWA 初版，不是已经在线部署的网站。
2. 自动油价接口尚未接入，因此不会显示伪造的实时价格；当前可手动填写挂牌价。
3. 浏览器本地数据只存在当前浏览器环境。清除 Safari 网站数据、换机或使用其他浏览器可能丢失数据，请定期导出 JSON 备份。
4. 日期提醒主要在打开应用时检查；PWA 不是持续后台运行的原生程序。iOS Web Push 需要 HTTPS、主屏幕安装、用户授权及服务端推送配置。
5. 加油量估算受优惠结算规则影响。若小票有实际升数，应优先填写实际升数。

部署方式（需要把这些文件放到 HTTPS 静态网站）：
- 将本目录所有文件上传到支持静态站点的托管服务。
- 确认站点使用 HTTPS，且 index.html、app.js、manifest.json、sw.js、icon.svg 都可访问。
- 在 iPhone 上用 Safari 打开站点。
- 点击“分享”→“添加到主屏幕”→“添加”。
- 从主屏幕图标打开，先测试添加、删除和导出备份。

如果使用 GitHub Pages，需先创建仓库并上传这些文件，再在仓库 Settings → Pages 中启用静态部署。请勿把备份 JSON 上传到公开仓库，因为里面可能有个人用车记录。
